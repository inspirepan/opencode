The present_file tool makes a file or directory visible to the user by rendering it in the preview panel.

When to use the present_file tool:
- After creating or modifying a file that should be presented to the user
- When the user would benefit from seeing the visual output of a file
- Presenting HTML files (rendered as a live web page)
- Presenting SVG files (rendered as inline graphics)
- Presenting Markdown files (rendered as a formatted document)
- Presenting Mermaid diagram files (.mmd/.mermaid) (rendered as diagrams)
- Presenting PDF files (rendered as paginated document)
- Presenting PowerPoint files (.pptx/.ppt) (opened with system default application)
- Presenting image files (.png/.jpg/.jpeg/.gif/.webp/.bmp/.avif) (rendered as zoomable image)
- Presenting a directory of images (rendered as a gallery grid)

When NOT to use the present_file tool:
- When you only need to read file contents for your own processing
- For temporary or intermediate files not meant for user viewing
- For plain text or source code files that have no visual rendering

How it works:
- Accepts a file path (absolute or relative to the workspace) or a directory path
- The file must already exist on disk (use the Write tool first if needed)
- The preview panel will open automatically and render the file content
- For Markdown files, local image references (png, jpg, svg, gif, etc.) are automatically inlined for preview
- For PDF files, the binary content is base64-encoded and rendered client-side via the built-in PDF viewer
- For image files, the binary content is base64-encoded and rendered as a zoomable image (click to enlarge)
- For directories, all image files are scanned and displayed as a gallery grid (up to 20 images, newest first)
- Calling present_file on the same directory again will refresh the gallery with the latest images

Batch image generation tip:
- Generate all images into a single directory, then present that directory to show them as a gallery
- You can present the directory early (before all images are done), then re-present it after generating more images to update the gallery

Supported file types:
- .html, .htm — rendered as a live web page in the preview panel
- .svg — rendered as inline scalable vector graphics in the preview panel
- .md, .markdown — parsed and rendered as a formatted document with GitHub-style styling in the preview panel
- .mmd, .mermaid — rendered as diagrams (flowcharts, sequence, state, class, ER, XY charts) in the preview panel
- .pdf — rendered via the built-in PDF viewer with zoom, page navigation and search in the preview panel
- .pptx, .ppt — opened with the system default application (e.g., Keynote, PowerPoint, LibreOffice Impress)
- .png, .jpg, .jpeg, .gif, .webp, .bmp, .avif — rendered as a zoomable image in the preview panel
- directories — scanned for image files and rendered as a gallery grid (newest first, max 20 images)
