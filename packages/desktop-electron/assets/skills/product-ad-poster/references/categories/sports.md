# Sports & Outdoors

Bold, motion-driven visuals with high energy, dynamic angles, and performance context.

## Color Tendencies

- Primary: bold black, electric red, vivid blue, high-vis orange
- Background: outdoor terrain, gym concrete, motion-blurred trails, gradient sky
- Accent: neon green, volt yellow, white flash, metallic silver
- Avoid: pastels, muted earth tones, overly soft or static palettes

## Photography Style

- High-contrast, sharp lighting to define muscle, form, and product structure
- Action freeze-frame or slight motion blur to convey speed and power
- Low angle or wide-angle for heroic, dynamic perspective
- Outdoor natural light (golden hour, overcast) for trail/field contexts
- Sweat, splash, dust, or particle effects to amplify intensity

## Props & Context

| Prop | Use For |
|------|---------|
| Athletic model | Demonstrating fit, function, and movement |
| Gym/track setting | Performance and training context |
| Trail/mountain | Outdoor, adventure, endurance narrative |
| Water splash | Waterproof, sweat-resistant claims |
| Timer/stopwatch motif | Speed, performance metrics |
| Equipment (weights, ball) | Sport-specific use case |
| Towel/bottle | Post-workout, recovery moment |
| Terrain texture | Ground, track, grass for environmental context |

## Scene Preferences

| Scene | Compatibility | Notes |
|-------|--------------|-------|
| studio | Good | Gear isolation, shoe detail, pack shots |
| lifestyle | Good | Gym, running, casual athleisure moments |
| flat-lay | OK | Gear layout, pre-run essentials |
| abstract | Good | Speed lines, particle bursts, energy graphics |
| seasonal | OK | Summer running, winter sports, seasonal drops |
| tech | OK | Shoe tech cutaways, fabric innovation diagrams |

## Text Treatment

- Bold sans-serif or condensed impact fonts; uppercase for headlines
- High-contrast text (white on dark, neon on black) for legibility
- Angled or dynamic text placement to match motion energy

## Mood Compatibility

| Mood | Fit | Notes |
|------|-----|-------|
| premium | Good | Pro-level gear, technical performance wear |
| balanced | OK | Everyday athleisure, casual fitness |
| energetic | Best | Default mood; matches action and intensity |

## Common Selling Points

- Lightweight / featherlight construction
- Breathable / moisture-wicking fabric
- Durable / reinforced materials
- High performance / competition-grade
- Comfortable / ergonomic fit
- Quick-dry / weather-resistant
- Anti-slip / high-traction sole
