# Electronics & Tech

Sleek, precision-driven visuals with dark tones, spec emphasis, and futuristic clarity.

## Color Tendencies

- Primary: deep blue, space black, silver, titanium grey
- Background: dark gradient (#0a0a0a to #1a1a2e), pure black, dark navy
- Accent: electric blue, neon cyan, warm amber (for premium), white glow
- Avoid: warm pastels, earthy tones, organic greens — feel low-tech

## Photography Style

- Controlled studio lighting with precise highlights on edges and surfaces
- Screen-on shots showing UI to demonstrate display quality
- Dramatic rim lighting or gradient backlight for silhouette definition
- Floating/angled product placement to convey lightness and modernity
- Macro shots for port details, material finish, button tactility

## Props & Context

| Prop | Use For |
|------|---------|
| Spec badge/icon | Highlighting key metrics (RAM, battery, Hz) |
| Screen glow | Demonstrating display brightness and color |
| Circuit/chip motif | Background pattern for performance narrative |
| Wireframe overlay | Design/engineering story |
| Hand holding device | Scale reference and real-use context |
| Desk setup | Lifestyle productivity scene |
| Charging cable/dock | Ecosystem, convenience story |
| Comparison inset | Before/after, gen-over-gen improvement |

## Scene Preferences

| Scene | Compatibility | Notes |
|-------|--------------|-------|
| studio | Best | Dark studio with controlled lighting is default |
| lifestyle | Good | Desk, commute, meeting context for use cases |
| flat-lay | OK | Unboxing, accessory ecosystem layouts |
| abstract | Good | Particle effects, light trails, data streams |
| seasonal | Avoid | Tech is season-agnostic; feels forced |
| tech | Best | Native scene; circuit, grid, holographic |

## Text Treatment

- Clean sans-serif or monospace fonts for spec callouts
- White or cyan text on dark backgrounds; high contrast required
- Spec numbers large and bold; supporting text thin and secondary

## Mood Compatibility

| Mood | Fit | Notes |
|------|-----|-------|
| premium | Best | Flagship devices, limited editions |
| balanced | Good | Mid-range, everyday tech, accessories |
| energetic | Good | Gaming peripherals, launch events |

## Common Selling Points

- High performance / fast processor
- Long battery life / fast charging
- Superior display / high refresh rate
- Ultra-lightweight / portable
- Innovative design / breakthrough tech
- Large storage / expandable memory
- 5G / Wi-Fi 6 / latest connectivity
