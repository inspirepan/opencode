# E-commerce Visual Elements Library

Visual building blocks for e-commerce KV compositions.

## Promo Badges

| Element | Use For | Style |
|---------|---------|-------|
| Discount ribbon | Percentage off, sale price | Angled corner ribbon, red/orange fill, white bold text |
| Circle badge | "NEW", "HOT", "TOP" labels | Solid circle, accent color, uppercase text |
| Price tag | Price display, crossed-out original | Tag shape with string, red for sale price |
| Countdown | Flash sale, limited time | Clock icon + "HH:MM:SS" or "X days left" |
| Star burst | Special offer, attention grab | Spiky circle, yellow/red, exclamation text |
| Banner strip | "Free Shipping", "Buy 2 Get 1" | Horizontal strip, high contrast fill |
| Shield badge | Quality guarantee, certification | Shield shape, gold/blue, check mark |

## Decorative Elements by Scene

### Studio
| Element | Description |
|---------|-------------|
| Gradient backdrop | Smooth color transition, subtle |
| Reflection plane | Glossy surface reflection under product |
| Spot light | Soft circular highlight on product |
| Shadow | Subtle contact shadow for grounding |

### Lifestyle
| Element | Description |
|---------|-------------|
| Props | Category-specific items (coffee cup, plant, book, fabric) |
| Surface | Wood table, marble, linen, concrete |

|---------|-------------|

| Texture base | Fabric, paper, board, marble slab |
| Geometric arrangement | Grid, radial, diagonal layout of items |
| Overhead perspective | Strict top-down camera angle |

## CTA Buttons

| Style | Description | Best For |
|-------|-------------|----------|
| Solid pill | Rounded rectangle, solid accent fill | Universal |
| Outline pill | Rounded rectangle, border only | Premium mood |
| Gradient pill | Rounded rectangle, gradient fill | Energetic mood |
| Arrow CTA | Text + arrow icon, no background | Minimal text |

## Text Treatment

| Treatment | Description | Best For |
|-----------|-------------|----------|
| Drop shadow | Text with soft shadow for readability | Busy backgrounds |
| Solid backing | Text on semi-transparent rectangle | Lifestyle scenes |
| Outline text | Stroke-only text, no fill | Overlay on product |
| Gradient text | Color gradient fill on text | Premium, tech |
