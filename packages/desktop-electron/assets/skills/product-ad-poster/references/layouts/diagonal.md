# Diagonal

Dynamic angled composition with product and text on opposing diagonal zones. Creates energy and directional movement.

## Composition

- Product zone: 45-55%, upper-right or lower-left diagonal
- Text zone: 30-40%, opposing diagonal corner
- Decorative zone: along the diagonal axis, motion lines, splashes, geometric shapes

## Spatial Guide

```
+----------------------------+
| HEADLINE  /               |
| subtext  /                |
|         /  +----------+   |
|        /   | PRODUCT  |   |
|       /    | (angled)  |   |
|      /     +----------+   |
|     /          [badge]     |
+----------------------------+
```

## Best For

- Fashion, streetwear, sportswear
- Youth-oriented or trendy products
- Action/sports equipment
- Sale or flash-deal promotions

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Good | Angled product on clean backdrop works |
| lifestyle | Best | Action shots amplify diagonal energy |
| flat-lay | Avoid | Flat-lay's top-down view conflicts with diagonal depth |
| abstract | Best | Geometric shapes reinforce the angle theme |
| seasonal | Good | Diagonal rain, leaves, confetti add motion |
| tech | OK | Can work with angular product design language |

## Prompt Notes

- Tilt the product 10-25 degrees to reinforce the diagonal axis; avoid exceeding 30 degrees or it looks unstable
- Add motion cues along the diagonal: speed lines, particle trails, gradient streaks
- Place the text block at the opposing corner with alignment parallel to the diagonal for visual cohesion
