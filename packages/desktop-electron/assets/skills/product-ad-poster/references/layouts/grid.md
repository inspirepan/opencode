# Grid

Multiple products or views arranged in a structured grid. Each cell roughly equal in size.

## Composition

- Product zone: 70-80% total, divided across grid cells (2x2, 3x1, 2x3, etc.)
- Text zone: 15-20%, header row or footer strip
- Decorative zone: cell borders, thin gutters, corner labels per cell

## Spatial Guide

```
+----------------------------+
|       [ HEADLINE ]         |
+-------------+------------- +
|  product A  |  product B  |
|  [label]    |  [label]    |
+-------------+-------------+
|  product C  |  product D  |
|  [label]    |  [label]    |
+-------------+-------------+
```

## Best For

- Color or style variant showcase
- Product bundles and gift sets
- Multi-SKU comparison at a glance
- Collection or catalog-style displays

## Platform Compatibility

| Platform | Fit | Notes |
|----------|-----|-------|
| taobao | Best | Standard for variant and bundle detail images |
| jd | Best | Clean grid aligns with JD's structured aesthetic |
| douyin | OK | Works for carousel; single frames feel catalog-like |
| xiaohongshu | Good | Square grids fit 1:1 well; 3:4 needs asymmetric grid |
| amazon | Best | Variant/comparison images are expected on listings |
| shopee | Good | Effective for bundle deals and multi-pack promotions |

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Best | Uniform backdrop across cells creates consistency |
| lifestyle | OK | Mixed lifestyle shots per cell can look disjointed |
| flat-lay | Best | Top-down per cell gives clean catalog feel |
| abstract | OK | Abstract per-cell backgrounds may compete visually |
| seasonal | Good | Uniform seasonal border ties the grid together |
| tech | Good | Spec callout per cell works for multi-device lineups |

## Prompt Notes

- Keep all grid cells identically sized with consistent gutters (2-4% of frame width)
- Use the same lighting, angle, and background within all cells for visual unity
- Limit to 4-6 cells maximum; more cells reduce per-product visibility on mobile
