# Closeup

Product detail or macro shot filling 80%+ of the frame. Focuses on texture, material quality, craftsmanship, or a specific product feature. Minimal text.

## Composition

- Product detail zone: 80-95%, filling the frame edge-to-edge or with tight crop
- Text zone: 5-15%, small logo/brand mark in corner, or single line overlay
- Decorative zone: none or minimal -- the texture IS the decoration

## Spatial Guide

```
+----------------------------+
|                            |
|    PRODUCT DETAIL          |
|    (macro / tight crop)    |
|    fills entire frame      |
|                            |
|                            |
|                [logo/name] |
+----------------------------+
```

## Detail Focus Options

| Focus | Description | Best For |
|-------|-------------|----------|
| texture | Surface quality, weave, grain, finish | Fashion fabric, leather goods, wood |
| ingredient | Cream swirl, serum drop, powder, liquid pour | Beauty, skincare, food |
| mechanism | Button, dial, hinge, port, clasp | Electronics, watches, hardware |
| pattern | Print, embroidery, engraving, label detail | Fashion, luxury, artisan goods |
| cross-section | Internal structure, layers, filling | Food, mattress, multi-layer products |

## Best For

- Luxury and premium product detail showcase
- Texture and material quality communication
- Food photography (appetizing close-ups)
- Beauty product texture (cream, serum, powder)
- Craftsmanship and quality signals
- E-commerce detail page supplementary images

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Best | Controlled macro lighting for maximum detail |
| lifestyle | OK | In-context detail (e.g., fabric on skin) |
| flat-lay | Avoid | Top-down wide view contradicts tight crop |
| abstract | OK | Abstract macro of product surface can work |
| seasonal | Avoid | Seasonal decorations compete with detail focus |
| tech | Good | Macro of circuits, ports, LED indicators |

## Prompt Notes

- Specify exactly which part of the product to focus on: "close-up of the serum texture as it drops onto skin" not just "close-up of the product"
- Describe the desired depth-of-field: "sharp focus on [detail area], gentle bokeh falloff at edges"
- Lighting should be directional to reveal texture: "side lighting from left to emphasize fabric weave and thread depth"
- If text is included, keep it to brand name or single tagline at frame edge -- never overlay text on the detail area
- For food: emphasize steam, gloss, juice, crumb -- sensory cues that trigger appetite
- For beauty: emphasize luminosity, translucency, smoothness -- sensory cues that suggest skin feel
