# Split

Left/right or top/bottom division with product on one side and text/copy on the other. Clear visual separation.

## Composition

- Product zone: 50%, left or top half
- Text zone: 50%, right or bottom half
- Decorative zone: dividing line area, small accents within text zone

## Spatial Guide

```
+-------------+-------------+
|             |             |
|  PRODUCT    |  HEADLINE   |
|  (photo)    |  body copy  |
|             |  features   |
|             |  [CTA]      |
|             |             |
+-------------+-------------+
```

## Best For

- Feature-heavy products needing description space
- Before/after or comparison visuals
- Products with detailed spec callouts
- Dual-language or bilingual layouts

## Platform Compatibility

| Platform | Fit | Notes |
|----------|-----|-------|
| taobao | Best | Detail images commonly use split layout |
| jd | Best | Suits JD's info-dense product pages |
| douyin | Good | Horizontal split works; vertical split better for 9:16 |
| xiaohongshu | Good | Top/bottom split fits 3:4 well |
| amazon | Best | A+ modules are designed for split content |
| shopee | Good | Keep text large for mobile readability |

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Best | Clean product photo pairs with text block |
| lifestyle | Good | Lifestyle shot on product side adds warmth |
| flat-lay | Good | Flat-lay on one half, specs on the other |
| abstract | OK | Abstract side may compete with text readability |
| seasonal | Good | Seasonal imagery on product side, promo text opposite |
| tech | Best | Product render left, spec list right |

## Prompt Notes

- Maintain a clear vertical or horizontal dividing line; use color block, gradient, or whitespace as separator
- Keep text zone background simple (solid or light gradient) to ensure copy legibility
- Product side should have consistent lighting independent of the text zone background
