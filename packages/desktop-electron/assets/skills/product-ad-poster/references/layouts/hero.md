# Hero

Single product centered and dominant, text overlaid or positioned below. Clean, dramatic, brand-forward.

## Composition

- Product zone: 50-60%, centered or slightly above center
- Text zone: 20-30%, overlaid on product or anchored bottom
- Decorative zone: corners and edges for badges, logos, subtle accents

## Spatial Guide

```
+----------------------------+
|        [badge/logo]        |
|                            |
|     +--------------+       |
|     |   PRODUCT    |       |
|     |   (center)   |       |
|     +--------------+       |
|                            |
|   [ headline / price ]     |
+----------------------------+
```

## Best For

- Single hero product launches
- Brand campaign key visuals
- Premium or luxury positioning
- Minimalist product showcase

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Best | Clean backdrop lets product dominate |
| lifestyle | Good | Context behind product adds story |
| flat-lay | Avoid | Hero needs depth, flat-lay conflicts |
| abstract | Good | Gradient or texture backdrops work well |
| seasonal | Good | Seasonal props frame the hero naturally |
| tech | Best | Dark studio + glow emphasizes product |

## Prompt Notes

- Place the product at dead center or slight upper-third; keep negative space generous around it
- Use a single light source from top-left to create depth and a subtle ground shadow
- Limit text to one headline and one price/CTA line to preserve visual clarity
