# Collage

Free-form magazine-style arrangement with irregular image blocks, overlapping elements, stickers, and handwritten-style annotations. Organic, editorial, curated feel.

## Composition

- Primary product zone: 30-40%, largest block, slight tilt (0-5 degrees)
- Secondary blocks: 2-4 smaller images (detail shots, in-use scenes, ingredient/material close-ups), 10-20% each
- Text zone: scattered annotations, handwritten-style callouts, sticker-like labels
- Decorative zone: tape strips, shadow edges, paper texture, doodles, washi tape, pin marks

## Spatial Guide

```
+----------------------------+
|  [sticker]                 |
|  +----------+  +------+   |
|  | PRODUCT  |  | detail|  |
|  | (main,   |  | (tilt)|  |
|  |  largest)|  +------+   |
|  +----------+     [note]  |
|       +--------+          |
|  [tag]| scene  |  [badge] |
|       | (small)|          |
|       +--------+          |
+----------------------------+
```

## Block Arrangement Rules

- Blocks should **overlap slightly** (5-15% edge overlap) to create depth
- Each block has a subtle **drop shadow or tape edge** to look like a physical photo
- At least one block should be **tilted 3-8 degrees** for organic feel
- **No strict grid alignment** -- stagger positions to avoid mechanical look
- Background should be a **surface texture**: kraft paper, cork board, marble, fabric, desk

## Best For

- Xiaohongshu grass-planting (种草) content
- Instagram story / editorial aesthetic
- Lifestyle and beauty product storytelling
- Multi-angle product showcase with personality
- Brand campaigns targeting young audiences

## Platform Compatibility

| Platform | Fit | Notes |
|----------|-----|-------|
| taobao | OK | Less conventional; works for detail images, not main |
| jd | Avoid | Too informal for JD's structured style |
| douyin | Good | Trendy aesthetic matches young audience |
| xiaohongshu | Best | This IS the native xiaohongshu visual language |
| amazon | Avoid | Conflicts with clean, structured A+ content |
| shopee | OK | Can work for flash-sale storytelling |

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Good | Clean product shots as individual blocks |
| lifestyle | Best | Mix of product shots and in-use scenes |
| flat-lay | Best | Top-down photos as collage blocks |
| abstract | Avoid | Abstract backgrounds conflict with the physical-photo aesthetic |
| seasonal | Good | Seasonal stickers and themed decorations fit naturally |
| tech | Avoid | Tech aesthetic contradicts the organic, handmade feel |

## Prompt Notes

- Describe the collage as "photos arranged on [surface]" -- kraft paper, wooden desk, marble counter
- Specify each block: "main product photo (largest, center-left), detail close-up (top-right, tilted 5 degrees), lifestyle shot (bottom-center, smaller)"
- Add physical collage cues: "masking tape on corners, slight drop shadows, paper edges visible"
- Handwritten annotations should be short and casual: "so good!", "must have", "daily fave"
- Keep the product block sharpest and largest; supporting blocks can be slightly softer
- Language note: for Chinese platforms, handwritten annotations in Chinese feel more authentic than English
