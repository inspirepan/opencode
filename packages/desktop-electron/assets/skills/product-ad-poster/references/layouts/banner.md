# Banner

Horizontal emphasis with product and text side by side in a wide format. Narrow vertical margins.

## Composition

- Product zone: 40%, left or center
- Text zone: 40%, right or opposite side
- Decorative zone: 20%, thin top/bottom margins, edge accents, background pattern

## Spatial Guide

```
+------------------------------------------+
|  +---------+    HEADLINE        [logo]   |
|  | PRODUCT |    subtext / offer          |
|  | (left)  |    [CTA button]             |
|  +---------+    ~~~~~~~~~~~~~~~~~~~~~~~~ |
+------------------------------------------+
```

## Best For

- Website header banners and carousels
- Platform top-banner ad slots (1200x400, 1920x600)
- Promotional strips and sale announcements
- Email header images

## Platform Compatibility

| Platform | Fit | Notes |
|----------|-----|-------|
| taobao | Best | Shop banner and promotion slots are wide format |
| jd | Best | Category banners and flash-sale strips |
| douyin | Avoid | Vertical feed; wide banner gets cropped or letterboxed |
| xiaohongshu | Avoid | 1:1 and 3:4 dominate; banner wastes vertical space |
| amazon | Good | Storefront headers and A+ banner modules |
| shopee | Good | Campaign banners and homepage carousel slots |

## Scene Compatibility

| Scene | Fit | Notes |
|-------|-----|-------|
| studio | Best | Product cutout on gradient fills banner cleanly |
| lifestyle | Good | Wide lifestyle shot as backdrop with text overlay |
| flat-lay | OK | Top-down cropped to strip can feel awkward |
| abstract | Good | Horizontal gradient or pattern fills the wide frame |
| seasonal | Best | Wide seasonal scene (snow, beach) as banner backdrop |
| tech | Good | Panoramic product lineup across the width |

## Prompt Notes

- Design at 3:1 or wider aspect ratio; never generate in portrait orientation for this layout
- Anchor the product to the left third and text to the right third, leaving breathing room at center
- Keep vertical content minimal; all elements should align to a single horizontal band
