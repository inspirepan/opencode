# Platform Specifications

## Taobao / Tmall (淘宝/天猫)

| Attribute | Value |
|-----------|-------|
| Main image | 800x800 (1:1), up to 1500x1500 |
| Detail banner | 790px wide, variable height |
| Default aspect | 1:1 |
| Background | White or light preferred for main; creative for detail |
| Text rules | Main image: product name allowed, avoid excessive text. Detail: free |
| Style | Clean studio shots for main. Lifestyle or promo for detail banners |
| Promo norms | Red price tags, "double 11" / "618" event branding, yuan sign prominent |
| Safe zone | 50px margin from edges for main image |

## JD (京东)

| Attribute | Value |
|-----------|-------|
| Main image | 800x800 (1:1), up to 1500x1500 |
| Detail banner | 990px wide |
| Default aspect | 1:1 |
| Background | White preferred for main image |
| Text rules | Main image: minimal text, product + brand only |
| Style | Tech-polished, feature-focused, spec-driven |
| Promo norms | Red/blue accent badges, feature comparison emphasis |
| Safe zone | 50px margin from edges |

## Douyin (抖音)

| Attribute | Value |
|-----------|-------|
| Feed ad | 1080x1920 (9:16) |
| Product card | 800x800 (1:1) |
| Default aspect | 9:16 for feed, 1:1 for product |
| Background | Creative, vibrant, attention-grabbing |
| Text rules | Large bold text, short punchy copy, must read in <2 seconds |
| Style | High energy, trend-driven, lifestyle-first |
| Promo norms | Flash sale urgency, influencer-style, price anchoring |
| Safe zone | Top 150px (status bar), bottom 200px (UI controls) for 9:16 |

## Xiaohongshu (小红书)

| Attribute | Value |
|-----------|-------|
| Post image | 1080x1440 (3:4) or 1080x1080 (1:1) |
| Default aspect | 3:4 |
| Background | Soft, lifestyle-aesthetic, warm natural tones |
| Text rules | Minimal commercial text; native, editorial feel. Heavy text looks spammy |
| Style | Lifestyle photography aesthetic, soft lighting, muted warm palette |
| Promo norms | Subtle product placement over hard sell. "Grass planting" (种草) style |
| Safe zone | 40px margin from edges |

## Amazon

| Attribute | Value |
|-----------|-------|
| Main image | 1600x1600+ recommended (1:1), minimum 1000px |
| Default aspect | 1:1 |
| Background | **Pure white (#FFFFFF) REQUIRED** for main image |
| Text rules | **NO text, logos, or watermarks** on main image (Amazon policy) |
| Style | Clean product-only shots. Studio photography. No lifestyle on main |
| Promo norms | A+ content allows creative; main image is product-only |
| Safe zone | Product fills 85%+ of frame (Amazon requirement) |

## Shopee (虾皮)

| Attribute | Value |
|-----------|-------|
| Main image | 800x800 (1:1), up to 2000x2000 |
| Default aspect | 1:1 |
| Background | White preferred for main; creative for promo |
| Text rules | Bold promo text encouraged for sale events |
| Style | Bold colors, promo-heavy, price-prominent |
| Promo norms | Orange/red theme, percentage badges, "Free Shipping" badges |
| Safe zone | 40px margin from edges |

## Generic

| Attribute | Value |
|-----------|-------|
| Default aspect | 1:1 |
| Background | Flexible |
| Text rules | Standard commercial design |
| Style | Balanced, professional |
| Promo norms | Standard commercial conventions |
| Safe zone | 40px margin from edges |

## Platform Selection Guide

| Product Intent | Recommended Platform |
|---------------|---------------------|
| Chinese domestic e-commerce | taobao |
| Chinese electronics/appliances | jd |
| Chinese short-video commerce | douyin |
| Chinese lifestyle/beauty review | xiaohongshu |
| International/Western market | amazon |
| Southeast Asian market | shopee |
| General / multi-platform | generic |
