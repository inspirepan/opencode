# Beauty & Skincare

Clean, luminous visuals with soft tones conveying elegance, purity, and sensorial luxury.

## Color Tendencies

- Primary: soft pink, rose gold, pearl white, cream
- Background: pure white, light blush, soft lavender, champagne
- Accent: gold foil, translucent blue (hydration), botanical green
- Avoid: dark/heavy saturated colors, neon, high-contrast clashes

## Photography Style

- Soft, diffused lighting with minimal harsh shadows
- Reflective surfaces (glass, water, mirror) to convey luminosity
- Macro close-ups for texture — cream swirl, serum drop, powder swatch
- Clean negative space around product for premium breathing room
- Skin-tone-complementary white balance; never overly cool or yellow

## Props & Context

| Prop | Use For |
|------|---------|
| Flower petals | Natural/botanical ingredient story |
| Water droplets | Hydration, freshness, aqua lines |
| Glass/acrylic blocks | Elevation, light refraction, premium feel |
| Silk/satin fabric | Luxury, smoothness association |
| Botanical sprigs | Herbal, organic positioning |
| Marble surface | High-end, clean backdrop |
| Texture swatch | Showing cream/serum consistency |
| Mirror/reflective tray | Doubling visual, adding depth |

## Scene Preferences

| Scene | Compatibility | Notes |
|-------|--------------|-------|
| studio | Best | Hero product with controlled lighting |
| lifestyle | Good | Vanity table, bathroom shelf, morning routine |
| flat-lay | Good | Routine sets, multi-SKU collections |
| abstract | OK | Gradient washes, fluid art for serum/essence |
| seasonal | Good | Spring florals, winter hydration themes |
| tech | Avoid | Conflicts with soft, organic positioning |

## Text Treatment

- Minimal, elegant serif or thin sans-serif fonts
- Low-contrast text (grey on white, gold on blush) for premium restraint
- Center-aligned or asymmetric editorial layout; avoid crowding

## Mood Compatibility

| Mood | Fit | Notes |
|------|-----|-------|
| premium | Best | Default for skincare, fragrance, luxury cosmetics |
| balanced | Good | Daily-use items, drugstore tier |
| energetic | OK | Color cosmetics, bold lipstick launches only |

## Common Selling Points

- Hydrating / deep moisture
- Brightening / radiance
- Anti-aging / firming
- Gentle / sensitive-skin friendly
- Natural / plant-derived
- Clinically tested / dermatologist recommended
- Lightweight / fast-absorbing
