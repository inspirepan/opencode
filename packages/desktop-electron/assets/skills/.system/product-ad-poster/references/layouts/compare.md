# Compare

Side-by-side or top-bottom comparison of two visual states. Emphasizes transformation, improvement, or difference. Clear dividing line between the two states.

## Composition

- State A zone: 45-50%, left or top (before / old / without / competitor)
- State B zone: 45-50%, right or bottom (after / new / with / our product)
- Divider: clear visual separator (line, gradient, zigzag, arrow, or label)
- Text zone: 5-15%, comparison labels on each side + headline at top or bottom
- Product zone: product can appear in State B, or centered on the divider

## Spatial Guide

### Variant A: Before-After (horizontal)

```
+-------------+-------------+
|   BEFORE    |    AFTER    |
|             |             |
|  (state A)  |  (state B)  |
|  dull/old   |  bright/new |
|             |  [PRODUCT]  |
|             |             |
+-------------+-------------+
   [ headline / CTA ]
```

### Variant B: Before-After (vertical)

```
+----------------------------+
|          BEFORE            |
|        (state A)           |
+----------------------------+
|          AFTER             |
|        (state B)           |
|       [PRODUCT]            |
+----------------------------+
```

### Variant C: Product vs Competitor / Old vs New

```
+-------------+-------------+
|  THEIR      |   OURS      |
|  PRODUCT    |   PRODUCT   |
|  (plain)    |   (better)  |
|             |             |
+---[VS or divider line]----+
|     [ headline / CTA ]    |
+----------------------------+
```

## Comparison Rules

- **State B (the positive side) should be visually dominant**: brighter, more saturated, or slightly larger
- **Divider must be obvious**: use a visible line, gradient edge, arrow, "VS" badge, or zigzag cut
- **Labels are mandatory**: "Before / After", "Without / With", "Old / New", or equivalent in target language
- **Consistent angle and framing**: both sides should show the same subject from the same angle/distance for fair comparison
- **Product placement**: product typically appears in State B or centered on the divider as the cause of the transformation

## Best For

- Skincare/beauty effect demonstration
- Cleaning product before-after
- Fitness/health transformation
- Product upgrade or version comparison
- Feature comparison against competitors (abstract)
- Home improvement / organization

| tech | OK | Feature comparison for electronics |

## Prompt Notes

- Be explicit about what changes between the two states: "left side: dull, dry skin with visible pores; right side: glowing, hydrated skin with smooth texture"
- Specify identical framing: "same lighting angle, same distance, same background -- only the skin condition changes"
- The divider style matters: "clean white vertical line" for clinical/premium; "dramatic diagonal slash" for energetic; "gradient fade" for subtle transition
- For Chinese platforms, common labels: "使用前 / 使用后", "旧款 / 新款", "别人家的 / 我们的"
- Avoid misleading comparisons -- keep the transformation realistic and within the product's actual capability
- Product can be overlaid on the divider line at 20-30% frame size as a visual bridge between the two states
